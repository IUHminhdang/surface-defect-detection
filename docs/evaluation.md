# Evaluation protocol

The project reports the required metrics:

- mAP50
- mAP50-95
- Precision
- Recall
- FPS
- Latency
- Parameters
- FLOPs
- Model size
- GPU memory
- Training time

The CSV schema follows the required output format and is generated under `experiments/<experiment>/`. The FPS benchmark must be run under the same hardware, image size, and deployment-oriented settings.
