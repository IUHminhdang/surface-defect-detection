# Baseline models

The project is positioned to benchmark detectors from the following families:

- YOLO11
- RT-DETR
- DINO
- Grounding DINO
- YOLO-World

The benchmark setup keeps the same dataset split and evaluation protocol where practical. Model selection is based on actual validation performance and reporting requirements rather than fabricated outcomes.

The codebase includes the training/evaluation scaffolding to write CSVs and to run experiments in a reproducible manner.
