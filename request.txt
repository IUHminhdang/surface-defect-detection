# 5. TRAINING STRATEGY

Do NOT simply train 50 epochs and use the final epoch.

Use:

```text
Maximum epochs = 50
        ↓
Warmup
        ↓
Learning-rate scheduler
        ↓
Validation every epoch
        ↓
Save best checkpoint
        ↓
Early stopping
```

Recommended defaults:

```yaml
epochs: 50

optimizer: AdamW

scheduler: cosine
warmup: true

early_stopping:
  enabled: true
  patience: 10

checkpoint:
  monitor: mAP50_95
  mode: max
```

Important:

* 50 = maximum epochs, not mandatory epochs.
* Select `best.pt` using validation `mAP50-95`.
* Save `last.pt` as well.
* Early stopping must monitor validation performance, not training loss.
* Record learning rate every epoch.
* Use gradient clipping only if needed.
* Use gradient accumulation only when GPU memory requires it.
* Do not intentionally increase gradients.

# 10. MODEL IMPROVEMENT

Choose the proposed improvement **from observed errors**.

Examples:

```text
Small-object failure
→ multi-scale / high-resolution features

Low-contrast failure
→ feature enhancement / attention

Domain shift
→ domain adaptation / feature alignment

Many false positives
→ hard-negative strategy / better training
```

Do not add modules without a clear hypothesis.
